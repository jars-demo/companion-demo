### Added

- The companion kit: `<Companion>`, `<Figure>`, pure behaviour rules and plain CSS motion.
- Six companions, each in its own folder with a README: Recei, Mochi, Bolt, Inky, Sprout and
  Toast, plus a fully commented `_example` (Pebble) to copy.
- A ten-chapter workshop and a facilitator guide for running it.
- The site: landing page, companion directory with live eyes, a playground that writes the
  code for you, and the workshop, with a companion of your choice living in the corner.
