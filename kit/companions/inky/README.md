# Inky

A drop of ink with big ideas.

**Personality:** Dreamy and thoughtful. Turns like a page between pages.

## Use it

```tsx
import { inky } from '@/kit/companions'

;<Companion character={inky} answers={answers} />
```

## Palette

| Part   | Colour    |
| ------ | --------- |
| body   | `#8b98f5` |
| ink    | `#141412` |
| cheek  | `#fda4af` |
| accent | `#c7d2fe` |
